# Cover Letter — FAANG (Google / Meta / Amazon / Microsoft)

**Format rules:**
- 1 page, 250–350 words, Arial/Calibri, PDF
- Amazon: they actually prefer NO cover letter (they use STAR behavioral answers in the app). Check each posting — many FAANG internships have no cover letter field. This letter is for when one IS requested.

---

[Your Name]
[City, Country] | [Email] | [Phone]
[LinkedIn URL] | [GitHub URL]

[Date]

[Company] Recruiting
[Role — e.g., Software Engineer Intern]

**Subject: Software Engineer Intern Application — [Your Name]**

Dear [Company] Recruiting Team,

I am a [X]th-year Computer Science student at [University] applying for the [Role]. [Company]'s work on [specific product/tech, e.g., infrastructure at scale / AI tools / developer platforms] is the reason I chose engineering — I want to learn how teams build systems that serve millions of users.

[Paragraph 2 — technical proof, quantified.]
My strongest project, [Project Name], is a [description] built with [stack] that [ships metric: serves X users / handles X req/s / cut latency by X%]. It is deployed with Docker and a GitHub Actions CI/CD pipeline, and I wrote [X] tests to keep coverage at [X]%. I have also solved [N] LeetCode problems, sharpening my skills in [topics]. My code and write-ups are on GitHub: [link].

[Paragraph 3 — why them.]
I am specifically interested in [team/product] because [honest specific reason]. [Something you learned from their engineering blog / a product you use.] I work well on teams — [one example: hackathon team / club / open-source PR] — and I am excited to learn from the engineers at [Company].

[Close.]
I would love the opportunity to contribute and grow during the [Summer] [Year] internship. Thank you for considering my application.

Sincerely,
[Your Name]

---

## Reminders
- Google: process is resume → phone screen → 2 coding interviews. Letter optional; if attached keep it short.
- Microsoft: resumes are the key; letters rarely read. Only attach if asked.
- Amazon: skip the letter, focus on STAR answers (Leadership Principles: Customer Obsession, Ownership, Deliver Results — prepare one story per principle).
- Meta University / Microsoft Explore: letters optional — the program forms do the work.
- Always attach the ATS-safe resume with GitHub link — that's what actually gets read.
