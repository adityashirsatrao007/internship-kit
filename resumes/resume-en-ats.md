# English ATS-Friendly Resume (Standard Format)

**Use this for:** Google, Meta, Amazon, Microsoft, Apple, Goldman Sachs, JPMorgan, Mercari, Rakuten, Sony, LY Corp — and every English-language application.

**Why this format (researched from ATS studies 2026):**
- Single-column layout → 91% ATS pass rate (vs 38% failure for two-column)
- Skills section at top → +41% ATS score
- Contact info in body (not header) → 94% pass rate
- Dedicated Projects section → 3.2x higher pass rate for beginners
- Metrics on every bullet → 2.4x callback rate at 75+ ATS score

**Rules:**
- 1 page (you are a beginner)
- Font: Arial / Calibri / Garamond, 10.5–12pt, 0.5–1 inch margins
- NO tables, text boxes, icons, photos, columns, headers/footers
- File name: `YourName-Resume.pdf` (PDF unless portal asks for .docx)
- Every bullet: action verb + what you built + tech used + metric
