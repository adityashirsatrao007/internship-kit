# 職務経歴書 (Shokumu Keirekisho) — Engineering Career History

**What it is:** The detailed Japanese work-history document. For software engineers, this is often MORE important than the rirekisho. Where the rirekisho is a factual record, the shokumu keirekisho is where you show your technical stack and project experience.

**When you need it:**
- Applying to traditional Japanese companies
- Applying for internships/full-time where HR asks for it
- Mid-career roles
- It's expected to be 2–4 pages for engineers (more detailed than an English resume)

**For interns/students:** If you have no work history yet, skip the standard version — use your **projects** as the content, formatted as project experience. Japanese companies accept this for new grads.

## Standard Structure

1. **Header:** Name, contact, date
2. **Career Summary (職務要約):** 3–5 lines, who you are as an engineer
3. **Technical Skills (技術スタック):** languages, frameworks, databases, tools
4. **Project/Work History (プロジェクト経歴 / 職歴):** the bulk — for each project: name, period, role, team size, tech stack, what you did, results
5. **Others (その他):** certifications, language skills

## Project entry template (for students = your GitHub projects)

```
■ プロジェクト名: [Project Name] (期間: 20XX年X月～20XX年X月)
役割: 開発 (Developer) | チーム: 個人 (or チームX名)
技術: Python / FastAPI / PostgreSQL / Docker

概要: [What the project does, in 1-2 lines]

担当業務:
・[Bullet point of what YOU did — use 〜を実装/〜を設計/〜を開発]
・[Another bullet]

成果・実績:
・[REST API を実装し、レスポンスタイムを40%短縮]
・[ユニットテストを実装し、カバレッジを80%に向上]
```

## Translation cheat sheet (for your bullets)

| English | Japanese |
|---|---|
| Built / Implemented | 〜を実装した / 〜を開発した |
| Designed | 〜を設計した |
| Developed a REST API | REST APIを開発した |
| Reduced response time by X% | レスポンスタイムをX%短縮した |
| Improved coverage to X% | カバレッジをX%に向上させた |
| Deployed with Docker | Dockerでデプロイした |
| Wrote unit tests | ユニットテストを作成した |
| Handled X concurrent requests | X件の同時リクエストに対応した |
| Search and pagination | 検索・ページネーション |

## Critical warning
**Do NOT machine-translate your English resume into Japanese.** The shokumu keirekisho needs localization, not translation — English bullets are concise, Japanese expects expansion with descriptive phrasing. If you're not confident, have a bilingual person review it before submitting.
