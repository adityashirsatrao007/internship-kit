## 4. What Japanese companies specifically look for (verified from 2026 postings)

| Company | What they assess | Implication for your profile |
|---|---|---|
| **NRI (Nomura Research Institute)** | 課題解決力 (problem-solving), チームワーク, 伝える力 (communication) | Show group projects + explanations |
| **Hatena Summer Intern** | Engineering fundamentals, team dev, code review | Highlight Git workflow, PRs, collaboration |
| **Optim R&D** | NLP/CV/optimization research, RAG, AI-driven dev | Emphasize RAG + IEEE research + PyTorch |
| **MonotaRO** | Practical building (FastAPI, Go, gRPC, infra) | Show shipped projects + CI/CD |
| **Dwango** | Real product dev, Japanese communication | Japanese language + shipped products |
| **Rakuten / Mercari / LINE** (typical) | Technical skill + Japanese or English fluency | Bilingual signals help |

**Japanese companies commonly check:**
1. **GitHub activity** — commit consistency, code quality, READMEs (your #1 asset)
2. **Collaboration** — PRs, code reviews, team projects (Japan values 協調性 = cooperativeness)
3. **Japanese language** — even JLPT N5 shows seriousness; N3+ dramatically widens options
4. **Honesty** — inflated claims get caught in interviews; keep metrics defensible

**Key point from japan-dev.com:** for international companies in Japan, a portfolio is
rarely a *requirement*, but it is the strongest **risk-reduction signal** for juniors.
Your GitHub is effectively your portfolio in Japan.
