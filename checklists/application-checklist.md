# Master Application Checklist (run for EVERY application)

Use this before every single submission. Missing one box = dramatically lower chance.

## A. Documents
- [ ] Resume saved as `FirstName-LastName-Role.pdf` (not "resume-final-v3")
- [ ] Resume is single-column, plain text, standard fonts, no tables/icons/photos
- [ ] Skills section mirrors the job posting's exact keywords (languages, frameworks, tools)
- [ ] Every bullet has a number/metric
- [ ] GitHub + LinkedIn links in the body (working, clickable)
- [ ] If Japan/traditional company → rirekisho prepared (see resumes/rirekisho-guide.md)
- [ ] Cover letter ready IF the posting asks (banks: yes; Amazon: no; others: check)
- [ ] Ran resume through a free ATS checker (Jobscan / Resume Worded) → 75%+ match

## B. Application form
- [ ] Applied within the first 2 weeks of the posting opening (rolling review everywhere)
- [ ] Exact role title copied from the posting (don't write your own variant)
- [ ] All fields complete — incomplete = instant reject at GS/JPMorgan
- [ ] Honest dates and details (companies cross-check)
- [ ] Personal statement / motivation field (if any): written specifically for THIS company, NOT pasted

## C. Company research (do BEFORE submitting)
- [ ] Read the company's engineering blog or news — know 1 specific thing
- [ ] Know the exact product/division you're applying to
- [ ] For Japan: confirm language expectation (English OK? JLPT required?) from the posting
- [ ] Check the visa support statement in the posting (paid internship? visa sponsorship?)

## D. Before the interview (if you progress)
- [ ] Re-read your own resume — every line is fair game
- [ ] Practice your 3 projects end-to-end (what was hard, why you chose the stack, one limitation)
- [ ] LeetCode: refresh top-20 patterns (two pointers, sliding window, BFS/DFS, DP, heap, binary search)
- [ ] Prepare STAR stories (Situation-Task-Action-Result) — one per key value
- [ ] Amazon: study Leadership Principles. Goldman/JPM: practice quant + data questions + video interview
- [ ] Prepare "Why Japan?" (if applicable) — honest, specific, not anime
- [ ] Test mic/camera (video interviews are standard now)

## E. After submission
- [ ] Log the application in a tracker (company, role, date, status, deadline) — spreadsheets or the Job Tracker project you're building
- [ ] Set reminders for: status check date, interview date, deadline
- [ ] Send a follow-up only if past 2 weeks with no response (short, polite, one email)

## The stack that works (from research)
| Goal | Tool |
|---|---|
| Track applications | Spreadsheet + your own Job Tracker app |
| ATS check | Jobscan / Resume Worded (free tiers) |
| Find internships | official portals + LinkedIn (filter: Internship) + SimplifyJobs GitHub + TokyoDev/JapanDev + Wantedly |
| Interview prep | NeetCode 150 + Pramp mocks |
| Japan company info | japan-dev.com, TokyoDev articles, Reddit r/movingtojapan |
